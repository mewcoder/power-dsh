# 侧边栏独立页面

## 标识、入口与范围

功能 id 为 `standalone-page`，设置行位于 **设置 → power-dsh → 界面**，在「显示版本号」之后、「会话搜索增强」之前，名称为「侧边栏独立页面」，英文为 `Sidebar page`。说明为「将功能页从设置侧栏移至主侧栏的独立页面」，英文为 `Move feature pages from the settings sidebar to a standalone page in the main sidebar`。开启后向宿主注册一个与设置弹窗并列的全局面板：主侧栏出现 power-dsh 图标入口，点击后在主区域打开功能页；关闭后移除主面板与侧栏图标，若用户正停留在该页面则回到当前会话。默认关闭。

页面承载全局指令、记忆、技能、MCP、工作区、归档、使用统计七个功能页，不包含「设置」「壁纸」Tab。设置弹窗继续保留 power-dsh 入口及全部开关，分类按通用、界面、功能、管理、精简、其他排列；内部分类新增 `management`，原 `enhancements` id 和所有配置键不变。「功能」仅包含第三方网页搜索与历史对话检索，「管理」包含上述七页的开关，「侧边栏独立页面」归「界面」。此分组只改变入口位置，不改保存值、页面迁移范围或独立页导航。开启独立页面时，七个功能页不再重复出现在设置弹窗侧栏，关闭后恢复。壁纸始终保留原生设置入口，不修改壁纸的开关或效果。

## 配置与行为

配置键 `standalonePageEnabled`，布尔值，默认 `false`，经原生 `configForms` 持久化。设置行复用标准设置行与保存反馈；保存失败时开关回到已保存值。

独立页导航按 `personalization`、`memory`、`skills`、`mcp`、`projects`、`archive`、`usage` 顺序列出已开启功能页；原生设置侧栏的管理入口与「管理」分类的开关采用相同顺序，壁纸仍在原位置。首次进入选择第一个可用页，同一 Client context 内再次进入保留上次仍可用的选择，不另写持久化偏好。功能开关关闭时对应 Tab 不出现；当前页被关闭时立即回到第一个可用页。全部功能关闭时显示「尚未开启功能页」及「在设置 → power-dsh → 管理中开启所需功能」，不显示空 Tab 或设置按钮。Tab 支持左右方向键循环以及 Home／End，仅当前 Tab 进入焦点顺序。

宽屏左导航、窄屏原生分段导航及缺席回退均使用「图标 + 文字」：功能通过 `pages.icon` 贡献自身设置入口的同一图标组件，装配层只负责渲染，不维护另一份图标映射。图标为 16px、继承文字颜色，与标签间距 8px；记忆使用大脑图标。图标 `aria-hidden`、不可聚焦，名称由文字提供，选择、键盘焦点与生命周期不变。

页面复用既有功能实现、状态和保存入口，不复制业务状态。宽屏使用左侧导航，窄屏顶部只保留与正文左边界对齐的分段导航；不显示插件标题、简介、设置齿轮或设置弹窗。功能页保留自身的一组标题和说明。导航常驻，正文独立滚动；切换功能时正文回到顶部，选中 Tab 自动进入导航可见范围。

分段控件直接复用宿主公共 `SegmentedTabs`，与用户指定的「标准模式 → 模式说明／如何使用」控件一致：中性圆角底板、细边框选中底板、等宽项及原生滑动效果，常态文字无下划线；原生键盘焦点样式保持不变。已核对桌面 `@deepseek-ai/dsh-client-ui-agent-preset@0.2.2-rc.2` 对公共组件的调用及对应源码。公共组件缺席时回退为等宽分段按钮，保留主题、关联 id、选中态及键盘操作，不导入内部 UI。只在本功能自有导航容器内查找选中按钮以滚入可见范围，不查询宿主或其他插件的 DOM。所有设置仅从宿主原有设置入口调整。

布局按独立页自身可用宽度响应，不以整个窗口宽度判断。可用宽度达到 960px 时采用 128px 左侧功能导航、24px 栏间距和自适应正文，宽度不足时恢复顶部原生分段导航。参考用户指定的 ZCode 居中限宽方式，七页正文统一最大 800px，设置正文仍最大 760px。技能与 MCP 按 220px 最小卡片宽度自动填列，宽独立页通常三列，窄屏逐步减列，不放大卡片或字体。正文与导航组成的内容组水平居中，保留 16–32px 左右留白，标题、搜索与内容靠左。

宽屏导航使用自有主题按钮与纵向 tablist，支持上下方向键，继续兼容左右键及 Home／End；窄屏保留公共 `SegmentedTabs` 及其缺席回退。通过 `ResizeObserver` 只观察自有根节点，同一功能不因导航方向改变而重新挂载或丢失草稿、搜索和分组状态；仅切换功能重置正文滚动。观察器不可用时保留顶部导航，卸载时断开观察。

外层内容组以 800px 正文容量统一定位，导航和标题起点不因切换功能而横向跳动。全局指令编辑器保持原有默认高度（最小 260px），不随窗口自动撑高，允许手动纵向调整；工作区沿用窄屏行布局；归档窄屏将搜索单列、筛选并排和行内操作移至下一行；使用统计保持三张摘要卡、图表按可用宽度调整高度，窄屏标题与趋势切换控件分行。

保留宿主顶部安全区，不把顶部 leading 控件的横向安全宽度叠加到整页正文。页面高度随主面板伸缩，内容上对齐，不垂直居中或固定列表／卡片高度。正文滚动视口延伸至主面板右边缘，限宽、居中和留白在视口内的内容层处理，滚动条不贴着卡片列形成中部竖线。极矮窗口中的左导航可独立滚动。技能与 MCP 使用自动列数，不再用 520px 断点强制单列，少量条目也保留空列而不拉伸填满整行。工作区窄屏将最近活动放在名称和路径下方、移除操作留在右侧，与设置内共用同一布局。

导航横向滚动不显示滚动条，保留触控板、触摸与键盘切换。正文及左导航的纵向滚动复用宿主透明轨道与主题滑块，通过自有容器上的原生几何变量使用 5px 滚动区、1px 透明滑块边距与 12px 轨道端部留白；不设置会覆盖宿主 WebKit 皮肤的 `scrollbar-width:thin`，不增加白色底槽或嵌套列表滚动。

## 生命周期、权限与兼容

主面板使用宿主 root 作用域 `main` keyed slot，侧栏入口使用同一 id 的 `sidebar.panellist` list slot；两个 slot 同时可用时才注册，任一缺失时不显示入口。关闭开关、模块卸载或宿主移除 slot 时释放两个注册；若当前选中的主面板仍是 power-dsh，先通过 `ctx.layout.selectPanel(null)` 返回会话，避免悬空主区域。页面本身不读取或写入会话数据，不新增网络、进程、文件或凭据访问，除宿主已授权 slot 外不查询或修改宿主 DOM。

## 验收条件与验证

- 开关开启后出现 `main:power-dsh` 与 `sidebar.panellist:power-dsh` 注册，关闭后两者移除；停留在页面时关闭开关，活动主面板恢复为会话。
- 独立页只包含已开启的七个功能页，不包含设置或壁纸；关闭当前功能后立即回到第一个可用页，全部关闭显示可恢复的空态；再次进入保留本 Client context 内有效的页面选择。
- 独立页开启时七个功能页不再注册到设置侧栏，关闭后恢复；壁纸入口保持不变，设置页中的全部开关仍可正常读写。
- 三种导航路径均显示相同的图标与文字；记忆为大脑图标，关闭记忆移除该项，切换独立页面不改变记忆子配置。
- 独立页开关位于「界面」，七个管理开关只在「管理」出现，第三方搜索与历史检索仍在「功能」；六个分类的顺序、键盘循环与保存权限正确，已有偏好不变。独立页没有插件标题和设置入口，空态引导至「管理」，关闭独立页开关返回会话，保存失败保留原状态与共享错误反馈。
- 宽屏左导航、窄屏顶部原生分段导航，整体水平居中且正文内容靠左；正文仅保留功能自身的一组标题和说明。滚动长页面时导航保持可见，切换功能后正文回到顶部；改变面板宽度保留当前功能、草稿和滚动位置。窄面板不撑破宿主，键盘切换后该项保持可见；公共分段组件缺席时仍可正常操作。
- 组件卸载后注册、订阅和样式随 context 释放，不改变任何功能配置或其他 slot 占用。

行为测试见[独立页面测试](tests/client.test.mjs)。实际 DSH 主面板与响应式视觉仍需在目标宿主中验收。
