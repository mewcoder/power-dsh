# 使用统计

模块 id：`usage-stats`；主开关 `usageStatsEnabled` 默认 `false`。模块的[定义](definition.ts)、[配置](config.ts)、[Host](host.ts)、[Client](client.ts)与[行为测试](tests/)在本目录维护。当前为**已实现源码**，实际安装与页面验收尚未执行。

## 标识、入口与范围

在 **设置 → PowerDSH → 管理** 打开「使用统计」开关，设置侧栏新增独立 **使用统计** Tab（与技能、MCP、全局指令、归档同样的 `settings.section` 接入方式，`order: 55`）。开关默认关闭、独立持久化，只控制统计页入口。开关与页面顶部说明均为「查看 Token 用量」。

目标：让用户不必逐个翻会话，就能看到指定范围内的总 Token、输入输出、缓存命中、会话与调用次数、累计运行时长，以及各模型的占比和每日趋势。

保留：DSH 的会话日志本身是宿主能力，本功能只读、只聚合，不写入会话、不修改任何配置或日志。明确不包含：费用估算、账户余额、远端或官方额度、按工作区筛选、按会话下钻、导出、自动刷新轮询以外的后台统计。Token 只取适配器上报的用量，不做字符数估算。

## 配置与行为

唯一配置键 `usageStatsEnabled`（`z.boolean().default(false).volatile()`，与现有开关一起经宿主 `configForms` 持久化）。统计结果是读取会话日志即时计算的派生数据，不另存、不缓存到配置。

- 页面挂载时读取一次，窗口重新获得焦点时再读一次；首次无数据时使用共享加载反馈（宿主 `StateDot ongoing` 与简短文字）。描述行右侧的 24×24 原生 ghost 图标按钮手动刷新，空闲用 14px `refresh-outline`，有数据刷新时换成原生加载指示，带本地化 Tooltip 和无障碍名称。页面底部不再放刷新按钮；读取期间按钮忙碌并禁止重复提交，已显示的旧数据保留，不重复展示页级加载提示。
- 页面顶部时间选择器靠左排列，整体高 28px（2px 内边距、24px 按钮、12px／18px 文字），与描述行间距 12px；自定义日期摘要接在控件右侧。控件为中性分段样式，顺序固定为「今天｜本周｜本月｜全部｜自定义」，默认「今天」。选中项使用主题分层底色与主要文字，不加业务色外框；窄容器自然换行。只保留当前页面状态，不持久化。
- 预设以报告生成时间在报告时区中的当前日期为基准，不能用最后活动日冒充「今天」；本周从周一开始，本月从 1 日开始。点击「自定义」时尚不切换范围，应用后才切到自定义，控件旁显示 `YYYY-MM-DD → YYYY-MM-DD`。
- 自定义日历浮层左下角提供「近 7 天」「近 30 天」两个轻量快捷按钮，右下角放取消／应用；两组共用底栏，窄视口自然换行。近 7／30 天包含今天；快捷按钮只填入两端日期，不关闭弹窗、不立即修改当前范围，统一点击「应用」提交。
- 页面按统计口径分成两组：第一组「所选范围」含三张卡片与模型用量列表，跟随顶部时间选择；第二组「全部历史」含 53 周热力图与趋势图，不受顶部范围影响，趋势图另设「近 7 天／近 30 天」缩放。两组保留各自的无障碍名称，不显示「所选范围」「全部历史」的可见分组标题；时间选择器下方 10px 直接接三张统计卡片，两组之间保持 24px 间距。
- 卡片在今天、本周、本月、全部及自定义日期范围下按日聚合；会话按主会话及其全部子 Agent 的活动日期合并去重，同一家族跨多日只计一次；普通分叉仍是独立会话，缺失父级的子 Agent 按现存家族计数。全部以本地报告时区的 0 点切分自然日，开始日与结束日均包含在内；不提供滚动小时范围。
- 「自定义」打开与触发按钮右边缘对齐的原生 `popover="auto"`，复用公共 `MenuSurface` 材质与原生菜单阴影，清除浏览器 Popover 的默认边框、背景和容器轮廓，日期格仍保留键盘焦点环；宽 280px、内边距 12px、日期格高 28px，受视口宽高约束并可滚动，空间不足时翻到上方。浮层无遮罩或居中标题，不圈定 Tab 焦点，点外部或 Escape 关闭。内容为近 7／30 天快捷范围、起止日期摘要、单月月历与选择阶段提示。月历周一开头，每月固定 6 行 7 列；第一次点击重设开始日，第二次完成结束日，反向点击自动排序，同日可选。第二次点击前悬浮或方向键移动会预览连续范围，起止深底、中间浅带；今天以小点标记，跨月日期为次要色。允许选择无记录的日期，日期由月历生成，不再使用原生 date 输入。
- 上下月箭头支持跨月选范围；方向键按日／周移动、Home／End 移到本周两端、PageUp／PageDown 按月移动并对短月日期截断。月历只保留一个日期进入 Tab 顺序，当前聚焦日期初始获得焦点，焦点可跨月份。优先展示当前已选区间的结束月份，近 7／30 天更新草稿与月历位置。未完成第二次点选时禁用应用，取消／关闭保留原范围、丢弃草稿；取消和应用返回触发按钮，浮层局部处理 Escape 并阻止关闭背后的设置页，原生 Popover 处理外部点击关闭与顶层显示，不添加全局键盘或指针监听。
- 顶部三张卡片依次为：总 Token 数（小字显示输入、输出）、缓存 Token 数（小字显示缓存率）、会话（主数字只显示会话数，小字仅显示累计运行时长）。Token 紧凑显示统一用「万／亿」单位（如 `1.2万`、`1.3亿`），不随界面语言改成 K／M／B；不足一万显示完整数字，卡片可悬浮查看准确数字；会话数用完整数字。普通输入、缓存读、缓存写为互斥输入桶，卡片输入为三者合计；缓存 Token 指缓存读取，缓存率为缓存读取 ÷ 全部输入，零输入显示 0%。总 Token 为普通输入、缓存读、缓存写、输出四项之和，不另用 usage.totalTokens 覆盖；reasoningTokens 不重复加到输出。官方 `tokenUsage` 还会从 `assistant/message`／`assistant/attempt` 的流内最后一个 `usage` 块回退读取，失败或被取消的尝试同样计费；同轮同步骤内最后一个用量样本完整替换前一样本（含分量减少或归零），按保留样本的日期与模型归属；没有用量的结算不覆盖已上报样本。每个保留非零样本的累计槽计一次调用，`llm/retry-started` 开启新槽，因此重试的成功请求与失败尝试分别计入。顶部不显示调用次数。
- 时长累计已完成 step/start 到 step/end 的实际跨度，包含步骤内等待、排除步骤之间闲置；未结束或缺起点的步骤不估算，不推算到当前时刻。崩溃恢复或分叉补写的 `step/end` 不算实际结束，已完成的早先步骤保留。按报告时区拆分跨午夜的时长，范围内只累计对应部分；并行会话分别累计。没有起点时不估算，提示通过悬浮说明提供。三卡等高，固定三列同一行，间距 8px、内边距 12px、名称 11px、主数字 18px；窄容器不改为两行，长数字与辅助文字在卡内省略，不撑破相邻卡片。不再另放组成条。
- 「Token 热力图」固定显示截至报告时区「今天」所在周的 53 个自然周（周一起始），不随最后活动日移动；每格按当日 Token 相对网格起点至今天之间的单日最大值分级，五级色阶使用宿主业务强调色叠在透明底上，主题切换自动跟随；今天以外侧 1px 半透明次要色描边标出，不改变格内填充；只保留按天一个维度，不提供每周／累计切换。格子为 padding 撑出的正方形、2px 间距、2px 圆角、不带星期列；月份在网格下方按变化锚定到起始列；空格子与今天之后尚未发生的日期都铺同一种低透明度中性底，整块网格始终是铺满的矩形，未来日期不带提示且不可聚焦，有数据的格子悬停时加强调色描边。整张网格只有一个 Tab 停靠点，初始为今天；方向键按日／周移动，Home／End 移到本周已发生日期的两端，导航不进入未来日期。月份标签锚定在包含该月 1 号的那一周，并按相邻锚点计算跨度；网格开头那个在范围之前就已开始的残月不标注，避免把未展示的历史说成从该月开始。月份标签只写月份，不带年份。每个格子经原生 `Tooltip` 只显示日期与当日 Token 用量；卡片标题右侧不加范围说明，也不另放色阶图例。整段没有任何已记录用量时，只显示一条空提示，不画空网格。
- 「Token 趋势图」按模型画平滑曲线（三次贝塞尔控制点限制在相邻数据点的范围内，曲线穿过各点且不超过峰值或跌破零值，SVG 裁剪边界外笔画），最多取所选范围内累计 Token 前 6 个模型，每个模型一色并在图例标注模型名；图例为带 `aria-pressed` 的切换按钮，点击取消选中后文字与色点置灰，同时移除该模型曲线及数据点提示，再点恢复。隐藏模型不改变其他曲线的颜色、纵轴比例或所选范围统计，全部隐藏时保留日期标签和可操作图例；趋势图不绘制底部轴线；选择只保留在当前页面，切换 7／30 日沿用，不写入偏好、不重读日志；卡片标题右侧固定放置「近 7 日／近 30 日」缩放，标题与控件用两列网格排列，模型图例独占下一行，避免名称长短与模型数量改变控件位置，以报告日为末端逐日补零；趋势只受自身缩放控制，不被页面范围裁剪，因此选「今天」时仍显示完整 7／30 天折线，不会退化为单点或空状态。没有用量时显示空状态。默认只显示曲线；悬停到某个模型的每日数据点时才显示同色圆点，并由公共 portal `Tooltip` 就近显示该日期、该模型及其当天 Token 数（沿用万／亿单位），无记录补零，不显示其他模型或插值推算值；空白区域不触发提示，不再使用整列提示和竖向定位线。每个点保留 12px 透明命中区域，圆点默认隐藏，悬停或键盘聚焦时显示为 6px，离开且失焦后隐藏。全图只有一个 Tab 停靠点，左右方向键按日期移动、上下按模型移动，Home／End 跳到当前模型窗口两端；切换 7／30 日保留仍可见的焦点，否则回到首条曲线的末日，不触发日志重读。
- 「模型用量」与三张卡片同口径，按页面时间范围统计：选「今天」只列出当天用过的模型，选「全部」汇总整段历史。按 Token 降序列出范围内的全部模型：每项用固定列网格排布：第一行为色点、模型名、11px 次要色右对齐 Token 数与固定 40px 右对齐占比，第二行为该行模型名下方整宽 3px 占比条；Token 与占比列定宽，多行右边缘严格对齐。占比以该范围合计为分母，请求次数按日行逐模型累计并放在该行悬浮标题里。模型名取结算声明的来源，失败尝试没有来源时取当时已记录的 `request/context` 路由。没有可靠路由则归为「未知模型」，不沿用相邻回复的模型；该用量仍纳入模型占比与趋势。模型名过长时省略。
- 读取失败显示可重试的页面级错误；部分会话日志无法读取时保留其余结果，并在页面顶部提示统计不完整，不伪造为零。

## 生命周期、权限与兼容

- 关闭开关即移除统计 Tab 与图标；卸载释放订阅与监听。统计结果、会话日志与开关偏好保留。
- 只读本机已落盘的会话日志：经原生 `sessionPersistence.list()` 取得可读会话与 `revision`，`open(id,'read')` 后从句柄的精确 `inheritedEventCount` 开始读取本会话自有事件，并立即 `close()`；祖先复制前缀不重复计入任何指标，读取 `assistant/message` 与 `assistant/attempt` 的 `usage`/`stream`与 `message.source`、`llm/retry-started` 的轮次与步骤，`request/context` 的路由，以及 `turn/start`、`turn/end`、`step/start`、`step/end` 与 `tool/call` 的时间戳和用于识别补写结束事件的轮次、结束原因。不写入、不删除、不修改会话，无网络、无进程、无凭据。
- 逐会话聚合按 `revision` 与报告时区缓存，最多 512 条，刷新时只重读有变化的会话；并发读取上限 4。日志读取或解析失败的会话被跳过并计入「不完整」，不影响其他会话。
- 原生接口依据（本机 DSH `0.2.2-rc.1` SDK 与官方仓库 `fcc0ad46` 源码核对）：`sessionPersistence.list({signal})` 的 `header.{id,createdAt,cwd,origin,parentSession}`、`revision`、`location`；`sessionPersistence.open(id,'read',{signal})` 的 `inheritedEventCount`、`read(offset,length,{signal})` 与 `close()`；事件 `assistant/message` 的 `data.usage`（`TokenUsage`：`inputTokens`、`outputTokens`、`totalTokens?`、`cacheReadTokens?`、`cacheWriteTokens?`）与 `data.message.source.{provider,model}`，以及 `turn/start`、`turn/end`、`step/start`、`step/end`、`tool/call` 的 `time` 与 `llm/retry-started` 的 `{turn,step}`。
- 服务缺席（无 `sessionPersistence` 的宿主）时，Host 方法抛 `usageUnavailable`，页面显示「当前 Host 不支持使用统计」，不伪造空列表或成功状态。Host 通过可选 `ctx.inject` 获取服务，缺席不会阻止其余功能加载。

## 验收条件与验证

可观察条件：
- 开启开关后出现「使用统计」Tab 与其图标，关闭后两者消失，且不增加重复监听或订阅。
- 三卡的主数字与小字均取所选范围的实际记录；输入包含三种互斥输入桶，缓存率包括缓存写入的分母，零输入不产生 NaN；失败尝试已计费的用量与成功请求一并计入。会话按家族跨日去重、请求按保留用量的累计槽计数、运行时长不计补写结束的步骤或步骤间闲置；复制的历史用量、调用与时长不重复统计。日期范围统一按自然日选择，跨日运行时长在本地午夜拆分，夏令时日使用实际经过时长。
- 热力图按本地时区归日，53 列周一起始，每日独立分级；没有每周／累计模式，切换页面时间范围不影响格子数与月份标签。
- 切换页面时间范围改变三卡与模型列表；切换趋势自身的 7／30 天只改变趋势点数与图例，三卡、热力图与模型列表不变。
- 趋势图只画前 6 个模型，无用量模型不出现；模型用量列表按 Token 降序且占比合计约 100%。
- 读取失败显示页面错误并可重试；部分日志失败时显示不完整提示，其余数据正常展示。
- 关闭开关或卸载后，焦点/窗口监听、订阅与 RPC 调用不再增加。

实现与测试：
- 纯逻辑 [usage-fold.ts](usage-fold.ts)：按会话折叠 `foldSession`、跨会话合并 `mergeUsage`、时区日键 `dayKeyFormatter`、连续天数 `streakDays`、补齐 `fillDays`。
- Host 服务 [usage-service.ts](usage-service.ts)：`list`/`open`/`read`/`close`、并发上限、`revision`+时区缓存、跳过失败会话、清理失效缓存。
- RPC 契约见 [rpc.ts](rpc.ts)，严格 codec 校验快照全部字段。新增 `sessionDays`（每个主会话家族的活动日期，不带标识）。Host 缓存仅保留日／模型聚合，不保留逐消息时间点、运行区间或正文；Client 不接收会话标识或原始事件。
- [行为测试](tests/usage-fold.test.mjs)覆盖四输入输出桶合计、独立 total 字段不覆盖分量、无 usage 调用计数、模型归属、时区归日、连续天数（含单日断档与过期断档）、日序列补齐、合并排序与不完整标记。

- [月历算法测试](tests/usage-calendar.test.mjs)覆盖闰日、跨年、短月截断与反向选择。
- [Host 行为测试](tests/usage-service.test.mjs)覆盖读取成功、缓存命中不重复读、revision 变化重读、失败会话被跳过、服务缺席报错与缓存清理，另覆盖按句柄精确切点排除继承前缀、嵌套子 Agent 合组、普通分叉保持独立、调用与步骤时长不重复。
