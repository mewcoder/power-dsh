# 鲸鱼动效

功能 id：`whale-motion`。入口：**设置 → PowerDSH → 界面 → 鲸鱼动效**。使用用户选定的第 12 款「尾巴打个招呼」的简化循环版本：身体与眼睛保持原位，只让尾巴轻挥两下、短暂休息，再自然重复。

## 配置与行为

`whaleMotionEnabled` 默认 `false`，经宿主 `configForms` 独立持久化，仅 owner 可保存；保存失败沿用共享设置反馈并保留宿主读回值。开启后仅注册 `sidebar.brand.mark`，立即自动循环摆尾，每轮 5.2 秒，沿用第 12 款的两次挥尾与停歇节奏。用户当前已开启的偏好保留，不增加模式或速度选项。

身体不做位移、旋转、缩放或形变，眼睛保持原形；不增加水面、气泡、粒子、淡出或整圈旋转。动画由一个尾部路径 morph 组成，不依赖鼠标、点击或键盘操作，没有悬浮监听与播放计时器。关闭后释放覆盖项，由宿主恢复原始鱼。字标、HARNESS、版本号、其他品牌插槽与页面标题均不变。

使用当前官方鱼的 `23.16 × 17.04` 原始画布、`size` 和 `currentColor`，不改变原生占位、文字颜色或布局。仅在自有图形内部预留少量裁剪余量，图形不覆盖旁边文字。路径形变仅作用于尾部，尾根连续衔接；相邻极值之间平滑插值，首尾几何相同。被动图形不接收指针事件，恢复宿主 Logo 行的原生窗口拖动行为。

## 接入、生命周期与权限

目标为 DSH `0.2.2-rc.1`。当前会话未暴露 Cordis Inspect 工具，依据为实际桌面发行包中 `dsh-client-ui-sidebar/lib/client.js` 的 `sidebar.brand.mark` root/single 声明与 `size:24` owner props，以及 `dsh-client-ui-brand-official` 的默认 `priority:0` 注册。实际 Web shell 与同版本 slot 公开实现均支持更低 priority 的覆盖和 disposer 恢复，故使用 `priority:-1`，保留官方注册，不停用官方品牌插件。缺少该 slot 时不注册，不猜 DOM 定位或导入内部 UI。

只注册鱼的公共插槽，不读取、替换或修改宿主 DOM；组件仅持有自己的 SVG。页面隐藏时暂停，恢复可见后继续原时间线；减少动态效果时显示原形静态鱼并暂停，取消减少动态效果后继续。卸载和关闭释放组件、可见性/媒体查询监听与 slot 订阅；开关值保留。没有 RPC、新依赖、网络访问、用户文件或凭据读取。动画数据随 Client 构建内嵌，不依赖预览目录或远程图片。

同一 `priority:-1` 被其他插件占用时保留原显示并在本设置行通过共享反馈报告；开关已保存值不伪造为关闭。用户可关闭后再开启重试，成功后清除反馈，不抢占更高优先级的第三方品牌项。

## 验收与证据

- 默认不覆盖品牌，开启只新增一个鱼 slot；重复通知不重复注册或重启循环，关闭或卸载恢复官方项并释放订阅。
- 原生 24px 宽度及比例不变，浅深主题跟随 `currentColor`，字标/HARNESS/版本号保持静态。
- 开启后自动循环；仅尾部形变，身体与眼睛在各关键帧保持原位，首尾闭合，不含整体变换或悬浮入口。
- 每轮 5.2 秒，轻挥两次后停歇，再开始下一轮；轮廓在自有裁剪范围内。
- 减少动态效果静态，页面隐藏暂停；重新显示沿原时间线继续，监听随卸载清理。
- 设置保存失败回滚，slot 冲突报告可处理错误且不更改其他设置。
