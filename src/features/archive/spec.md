# 归档

模块 id：`archive`；页面入口开关 `archiveManagerEnabled` 默认 `false`，自动归档 `autoArchiveDays` 默认 `0`（永不）。模块的[定义](definition.ts)、[配置](config.ts)、[Host](host.ts)、[Client](client.ts)与[行为测试](tests/)在本目录维护。当前为**提案+已实现源码**，实际安装与页面验收尚未执行。

## 标识、入口与范围

在 **设置 → PowerDSH → 管理** 打开「归档管理」开关，设置侧栏新增独立 **归档** Tab（与技能、MCP、全局指令同样的 `settings.section` 接入方式，`order: 54.5`）。管理开关与左侧入口均排在工作区之后、使用统计之前。开关默认关闭、独立持久化，只控制管理页入口。开关行与页面标题下的说明统一为「管理已归档会话」（英文 `Manage archived sessions`），不再写成「查看并恢复…」。

目标：在设置中查看全部已归档会话，按工作区分组、按标题搜索，并逐条恢复回原生列表。页面顶部保留自动归档的阈值偏好。

归档状态属于宿主；页面支持查看、取消归档、单条永久删除、工作区或全局批量永久删除，以及按闲置天数自动归档。自动归档不会删除转录。

## 配置与行为

配置键（均经宿主 `configForms` 持久化）：

- `archiveManagerEnabled`（布尔，默认 `false`）：只控制「归档」页入口。
- `autoArchiveDays`（数值，默认 `0`）：唯一的自动归档偏好，`0` 表示「永不」。只接受 0／7／14／30／60／90，其他值回退 0。没有独立开关，避免开关与阈值互相矛盾。
- `autoArchivedSessions`（字符串数组，默认 `[]`）：保留以前写入的永久豁免，不清空、不裁剪，也不根据当前归档状态重建；无对应 Client 标量设置。

归档数据归宿主，本功能不另存、不缓存到配置。

- 打开页面即读一次完整归档集合；窗口重新获得焦点时再读一次，保证宿主导航产生的变化可见。
- 行内第二行时间是该会话的**最近活动时间**，与原生侧栏给会话行标注的时间同源：优先取原生 `sessionController.list()` 返回的 `items[].updatedAt`（原生 `Math.max(header.createdAt, lastPromptAt)`），列表缺少该会话或列表读取失败时回退到标题事件的 `updatedAt`，再回退为不显示。
- 列表按工作区分组，分组顺序沿用原生工作区顺序；不属于任何工作区的归档会话归入末尾的「未分组」。
- 工作区实际目录（取自原生 `workspaceController.follow(signal)` 基线 `items[].path`）不占用分组标题行的版面：标题行只保留文件夹图标、分组名、分组名右侧的折叠箭头与行尾会话数量。完整路径挂在标题折叠按钮上，经原生 `Tooltip` 在鼠标悬浮或键盘聚焦时显示（`delayMs: 0`、`maxWidth: 520`），路径不参与搜索命中。路径缺失（旧 Host 未提供、或「未分组」分组）时不挂 Tooltip，也不补占位或猜测目录。
- 每个工作区分组**默认折叠**，标题行是可聚焦的折叠按钮：文件夹图标、分组名、分组名右侧的箭头依次排列（箭头收起时旋转 -90°，展开时不旋转），随后是该组会话数量；点击或按 Enter／空格折叠／展开；各组状态互相独立，只在本次页面停留期间保留，不持久化。搜索有内容时命中分组强制展开且标题按钮不切换折叠，清空搜索后恢复折叠状态。
- 搜索只在标题与工作区名上做本地过滤，空查询展示全部；无结果显示「未找到匹配的归档会话」，完全无归档显示「暂无归档会话」。
- 排序支持「更新时间」「创建时间」两种，作用于每个分组内的行；排序与工作区筛选两个下拉复用宿主原生设置选择器样式（36px 高、`--dsw-alias-bg-module-platform` 底、无描边、`--dsw-radius-md` 圆角、左右 14px 内边距、14px／22px 文字、名称与 16px 下箭头间距 12px、hover 使用 `--dsw-alias-interactive-bg-hover`），与「设置 → 语言」及技能页工作区选择器一致。工作区筛选可在「所有工作区」与各工作区之间切换，只显示所选工作区的归档会话（「未分组」不作为筛选项）。
- 行尾提供「删除」「取消归档」；分组右侧菜单和页面顶部提供各自范围的「全部删除」。使用原生 Modal 确认，明确永久删除无法撤销。
- 单条「取消归档」调用原生恢复；成功后以 Host 返回的最新归档集合重载页面，该项从列表消失。恢复期间该行按钮置为忙碌并禁止重复提交。
- Host 只删除仍在归档且未打开、未运行的会话，并要求原生 JSONL 写锁和可验证的单代转录。暂存文件后清除归档标记，失败时尽量把文件放回，不覆盖新文件。无法确认存储或发现异常时拒绝操作。
- 确认框冻结会话 ID 并显示对应数量。全局和分组的「全部」包括搜索隐藏的会话；全局也不受工作区筛选影响。刷新期间不能确认；目标集合变化则关闭确认框。批量逐条提交，页面关闭后不继续发起删除。
- 首次读取使用共享加载反馈（宿主 `StateDot ongoing` 与简短文字）；已有列表刷新时保留分组和展开状态，只增加紧凑加载反馈。加载失败显示可重试的页面级错误；恢复失败保留可恢复状态并给出错误。页面打开期间 Host 连接代际变化时自动重新读取归档并清除旧错误，避免插件重载后停留在失效请求的错误状态；提交恢复期间跳过焦点刷新并丢弃提交前的旧列表响应。

## 自动归档

归档页顶部固定一张「自动归档」卡片，位于页面标题与列表之间；该偏好只作用于本页，不在 **设置 → PowerDSH** 主设置页重复出现，左侧也只有一个「归档」入口。

- 右侧为原生 Menu 下拉，选项为「永不」与 7／14／30／60／90 天，默认「永不」。
- 已核对的 0.2.2-rc.1 宿主在启动、阈值变化时及每天检查；只归档有明确最后活动时间、已超过阈值且未置顶、未运行的会话，跳过空白和子代理会话。其他宿主保留偏好；未核对其队列契约前不运行扫描。
- 保存失败在该行内显示共享错误反馈，并关联下拉控件；配置未就绪、只读、保存中或页面已卸载时禁止提交，权限变化关闭已展开菜单，旧菜单回调重新核对当前权限，连续选择只发起一次写入。

扫描仅以列表作初筛，以原生会话观测核对真实活动；不能用创建时间替代未知的最近活动。原生归档队列中再次检查置顶、活动和阈值；已排队在归档之前的置顶会生效并挡住归档。归档后读回，发现迟到的活动变化时尝试取消归档。

在归档前持久保存会话豁免并读回确认，写入失败则跳过。已保存的豁免不会因竞争失败而清除，防止用户恢复后再次被自动归档。宿主没有待提交置顶意图接口，归档之后才排入的置顶仍按原生规则处理。

## 生命周期、权限与兼容

- 关闭开关即移除归档 Tab 与图标；卸载释放订阅与监听。归档数据、原生归档状态与开关偏好保留。
- 恢复与自动归档走原生工作区接口。永久删除只处理核对过的转录文件，不清理附件、外部备份或已读副本。
- 原生接口依据：已核对本机安装包 `0.2.2-rc.1` 的 `dsh-api-workspace-controller`、`dsh-workspace`、`dsh-api-session-controller` 与 `dsh-session-persistence`。展示复用 `workspaceController.follow`、`sessionQuery.readTitleSnapshots` 与 `sessionController.list`；恢复用 `workspaceController.unarchiveSession`。未取得此会话的实时 Cordis Inspect 工具。
- 写锁阻止其他写入者，不能锁住原生只读操作或恢复队列。暂存和归档状态不在同一事务；进程中断或回滚冲突时可能留下待恢复的暂存文件，不承诺跨进程原子删除。
- 服务缺席（例如无 `workspaceController` 或 `sessionQuery` 的宿主）时，Host 方法抛 `archiveUnavailable`，页面显示「归档管理暂不可用」，不伪造空列表或成功状态。Host 通过可选 `ctx.inject` 获取服务，缺席不会阻止其余功能加载。

## 验收条件与验证

可观察条件：
- 开启开关后出现「归档」Tab 与其图标，关闭后两者消失，且不增加重复监听或订阅。
- 已归档会话按工作区正确成组，「未分组」收纳无工作区的归档会话。
- 分组标题行不显示目录文字；悬浮或键盘聚焦标题按钮时出现原生 Tooltip 显示完整路径，「未分组」与缺少路径的工作区不出现 Tooltip。
- 每个工作区分组默认折叠，行隐藏在标题下；点击标题展开后该组行显示、其他组不受影响，箭头位于分组名右侧并随状态旋转；搜索命中折叠组时自动展开，清空后恢复折叠状态。
- Host 只删除仍在归档且未打开、未运行的会话，并要求原生 JSONL 写锁和可验证的单代转录。暂存文件后清除归档标记，失败时尽量把文件放回，不覆盖新文件。无法确认存储或发现异常时拒绝操作。
- 搜索命中标题或工作区名，清空后恢复全部。
- 排序切换更新时间/创建时间时组内顺序随之变化；工作区筛选只显示所选工作区并排除「未分组」。
- 点击「取消归档」后该项从归档列表消失，原生列表恢复该会话；恢复失败保留该行并给出可重试错误。
- 单条、分组和全局删除按确认范围执行；正在使用或存储不可确认的会话保持可恢复。自动归档跳过缺少活动证据或已置顶的会话。
- 加载失败显示页面错误并可重试，不显示为空列表。
