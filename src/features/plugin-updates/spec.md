# 插件更新

## 标识、入口与范围

功能 id `plugin-updates`。PowerDSH 设置页底部显示本插件的运行版本与「检查更新」按钮，各分类共用一处。在「其他」提供独立持久化开关 `pluginUpdatesEnabled`，默认开启；关闭仅隐藏此入口，不改变安装来源和已经交给市场的任务。功能不检查 DSH 宿主更新，不自动安装或定时检查新版。

## 配置与行为

用户主动检查时先发现同源 dsh-market 的公开 update API v1，要求正确 schema、检查／更新／进度能力和已核对的端点。本轮按市场 `1.73.19`、提交 `da774820fd49f4915461ff2031eedbef9b48dfe7` 的 `UPDATE-API-V1.md`、`routes.ts`、`update-api-v1.ts` 实现；该 API 当前为 beta，缺席、旧版、鉴权失败或结构改变都明确提示通过插件市场处理，不调用旧版私有 mutation。

只查询 `power-dsh`。同时匿名读取本项目 GitHub 最新正式 Release，验证版本、标签、固定附件名与公开仓库下载地址。市场的 Git 来源版本可能是提交号，须解析正式标签（含 annotated tag）并核对市场目标提交等于 Release 提交后才能显示「更新到 x.y.z」。归档路径的版本须与正式 Release 版本一致；local／linked／generation 来源不在此处转换。没有可靠目标显示「未确认可用更新」，不能把 API 失败或未知版本说成已最新。

有新版时显示目标版本、官方 Release 更新日志链接和「更新」按钮。点击打开宿主公共 Modal，显示当前 → 目标版本及可能需要刷新／重启的说明；取消不写入。确认时重新检查目标和安装基线，变化则要求重新检查，不静默接受另一个版本。POST 只发送固定包名，市场持有安装、兼容检查与恢复；本插件不停止自己、不执行 pnpm、不写 profile manifest、patch 或文件，不绕过市场发布等待和运行中任务保护。

市场接受后按 operationId 查询其公开进度，只有返回成功且安装版本达到已确认目标，才显示更新完成；要求刷新或重启时明确说明并提供用户主动的界面刷新入口，不自动重载或退出。失败、取消、回滚、记录丢失和无法确认完成分别显示，保留可恢复状态，不自动重发 mutation。网络失败后的更新状态可能未知，应到市场确认，不能再次直接发起安装。

## 生命周期、权限与兼容

常态不发网络请求；仅用户检查或恢复本页面已记录的更新任务时请求。发现与更新请求走当前页面同源、保留代理路径前缀、携带原生会话 cookie、禁止重定向；GitHub 请求匿名且不携带 cookie。页面只在配置 ready 且 writable 时允许检查与更新。关闭页面／开关或卸载取消本页面的读取与进度定时器，不能取消市场持有的安装。已接受 operationId、确认版本和市场 bootId 仅暂存在当前标签页 sessionStorage，并按页面路径隔离；重新打开时校验同一 Host bootId 后继续读回，不以旧记录操控新 Host。存储失败不撤回已经接受的任务，提示到市场确认。

错误使用共享反馈与固定双语文案，保留检查结果；不显示原始 HTTP 响应、路径、配置或进程输出。不会因超时自动重试更新。未知或更高版本、开发版本不提供降级；不提供自建下载器或替代重启机制。Inspect 本轮不可用，宿主依据为已核对 `0.2.2-rc.1` 桌面协议同源转发、公共 Button／Modal 及运行中的 configForms 契约；无需新增宿主接口或生产依赖。

## 验收条件与验证

测试覆盖默认零请求、只读／开关、来源与 Release／tag 校验、当前版与新版、重复点击、确认与取消、目标变化、API 缺席／错误、任务进度与实际版本、刷新／重启提示、sessionStorage 恢复和 Host 变化、卸载及迟到响应。静态检查和内存测试不等于真实插件自更新验收；本轮不修改日常 profile，不执行真实升级或自动发布。
