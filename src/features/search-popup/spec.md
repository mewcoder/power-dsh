# 会话搜索增强

模块 id：`search-popup`；唯一开关 `searchPopupEnabled` 默认 `false`，设置页显示为「会话搜索增强」，开启后自带标题与正文搜索。模块的[定义](definition.ts)、[配置](config.ts)、[Client](client.ts)、[Host](host.ts)、[策略](enhance-policy.ts)、[样式](styles.ts)、[文案](locales.ts)与[行为测试](tests/)在本目录维护。

入口：**设置 → power-dsh → 界面 → 会话搜索增强**，通过宿主 `configForms` 持久化；设置行经 Host 的 `setSearchPopupEnabled` 策略写入，不能只改偏好，不提供对话设置工具。说明固定为「在弹窗中搜索会话标题与正文」，英文为「Search session titles and content in a popup」；重启要求仅在运行中全文引擎尚未启用时通过搜索框占位符提示，不在设置行常驻显示。不再提供独立搜索增强开关或 RPC；旧 `searchEnhanceEnabled` 不再控制行为，保存唯一开关时移除旧字段。已有弹窗开启但旧增强关闭的安装无需再次开启：第一次非空内容请求按需补齐引擎配置，运行中的旧引擎仍禁用时显示重启提示；不在启动或最近会话预览时改写引擎。内部配置键与 RPC 名称保持不变。

## 范围与行为

### 搜索弹窗（searchPopupEnabled）

结果行高 54px（含上下各 6px 内边距），标题和摘要行高维持 20px／18px、间距 3px，行间距 2px；加载骨架同步为 54px。标准 520px 面板在列表顶部可完整容纳 7 行，减少底部摘要刚好被裁切的情况；小视口仍使用列表内部滚动。

开启后，点击侧栏原生搜索按钮（宽栏与窄栏两处放大镜）改为打开面板；桌面端按平台主修饰键＋K（macOS 为 Cmd+K，Windows/Linux 为 Ctrl+K）、网页端为主修饰键＋Alt+K 时同样弹出。顶部搜索框参考用户提供的「自动化任务」搜索框及 `TaskManagerPage.module.css`：52px 顶部区域内上下留白 8px、左右 16px，独立 36px 高输入框、12px 圆角、0.5px `border-l3` 描边，悬停为 `border-l2`、聚焦为 `state-business-primary`；左侧 14px 放大镜，文字 13px／20px，非空时右侧为无圆底的线形叉号、28px 命中区。取消原有通栏底部分隔线，不改变面板总高与列表容量。占位符随范围切换为「搜索会话标题…」「搜索会话标题（重启 DSH 后搜内容）…」或「搜索会话标题和内容…」。头部左侧显示「最近会话／搜索结果」，右侧为工作区筛选，不渲染键盘提示。中部为固定高度滚动列表。空查询展示当前范围最近 10 条会话，按 `updatedAt` 倒序、同序按 id。方向键选择，Enter 经 `uiWorkspace.openSession` 打开并关闭面板；Esc 或点击遮罩关闭，清空按钮回到最近会话。面板打开时重复搜索手势只回焦输入框，不重复请求、不叠加面板、不重置滚动位置。

结果行采用双行布局：第一行是无前导图标的标题，行尾显示工作区图标与名称；第二行是摘要，行尾显示 `updatedAt` 的本地化月日与 24 小时时分，语言取 `document.documentElement.lang`。工作区归属优先按 `sessionIds`，其次按 cwd 所在目录推断；未归属时省略名称。摘要围绕首个命中截取可见窗口并标注省略号。标题和摘要以主题链接色 `--dsw-alias-link` 逐处高亮，忽略大小写，不加底色。仅标题命中时，增强索引可用则返回最新一条消息预览；增强关闭、原生回退或没有可读消息时不伪造摘要。

空查询的最近会话第二行显示当前可见对话中最近一条有正文的用户或助手消息，忽略纯工具调用，合并空白后截断显示。摘要不依赖全文引擎。仅面板打开且查询为空时经 owner-only `readRecentSessionPreviews` 批量读取当前范围前 10 条，最多同时读取 2 条；不启动全文索引、不枚举目录、不读取其余会话、不后台轮询。Host 最多缓存 10 条摘要并合并同版本并发读取，以客户端活动版本、活跃会话实例/序号/内容代际和会话事件按需失效；优先借用活跃会话观察切片并从当前节点末端寻找正文，冷会话回退公开 `readSurface`，观察租约始终释放。服务替换或卸载清理缓存并隔离迟到响应。标题先可用，摘要补齐时保持行序与选择；关闭、输入或工作区变化后忽略旧摘要。缺少消息时第二行留空；读取失败保留标题与打开操作，复用共享错误反馈并支持重试。

工作区下拉复用原生 `Menu`，包含全部工作区和已登记项，按该工作区的 `sessionIds` 限定范围。最近会话、本地标题及增强正文均先筛选可见性和工作区，再按最近活动截断；子代理、空白、归档和列表外 id 不成行。增强正文经 owner-only `power_dsh#powerDsh/searchSessionContent` 查询，返回 `{sessionId, snippet}` 与标题预览；索引不可用时回退原生 `session.search`。正文与标题合并去重后按最近活动混排，数量以宿主 `searchResultLimit` 为上限，缺失时回退 40。搜索完成且显示条数达到上限时，底栏左侧显示「仅显示前 {n} 条结果，请缩小搜索范围。」，右侧保留数量；n 取实际显示上限，不为提示另行扫描或统计总数。加载中、未满一页或空查询最近会话不显示此提示；窄屏单行省略且悬停可见全文。原生回退受其有界结果页与 FTS 召回限制，可能在过滤后少于上限；增强路径不受不可见会话挤占名额的影响。不提供文件搜索或「全部／文件」标签。

查询词去除 NUL，截断到 500 个 UTF-16 码元且不截断代理对。内存路径等待输入停顿 100ms，原生回退保持总计至少 250ms 的输入等待，索引检测已经耗去的时间不重复等待。查询从输入变化当次渲染起显示两行骨架，等待标题、正文命中及预览合并完成后一次显示完整列表，不先显示标题再替换。查询、工作区、重试、开关变化或面板关闭后丢弃旧结果，并中止可取消的原生请求；新范围不得短暂展示旧范围结果或错误。骨架仅以 `role="status"` 提供读屏名称。结果按最近活动一次性混排，不分组。失败后回退本地标题，以[共享错误反馈](../../../docs/error-handling.md)呈现「搜索失败，请重试」、可复制详情与重试动作，不在正文显示原始异常。索引禁用时回退标题并将占位符切换为待重启状态；索引建立竞态（原因含 `did not stabilize`）显示「全文索引正在建立（有会话正在写入），稍后重试」，不显示失败红色。底部仅显示结果计数；完成且无匹配时居中显示「没有找到匹配结果」与提示，仅保留文字，不显示图标或插画。宿主缺少 `sessions.search` 或 `uiWorkspace.openSession` 时显示「当前宿主无法搜索会话」。关闭面板保留查询，下次打开全选。

关闭开关立即移除两类拦截监听并关闭已打开的面板，搜索入口恢复原生内联展开；卸载或停用 power-dsh Client 同样移除监听与 overlay 注册，不保留任何持久状态。偏好保存在宿主 `configForms`，重新加载 Client 后按已保存值重新生效。

### 内置正文搜索

开启弹窗时，Client 经 `power_dsh#powerDsh/setSearchPopupEnabled` 请求 Host 策略改写宿主部署配置：在原生 `configEditor` 中找到 `session-query-sqlite` 条目（`options.id` 与 `options.name` 双重匹配，禁用条目不可用），把挂载配置改为 `openAt: 'first-search'` 与持久化派生索引路径 `<profileContext.home>/power-dsh/session-query-index.sqlite3`，写前比对、写后读回核验，随后写入自身条目的 `searchPopupEnabled` 并再次读回；已匹配时跳过引擎条目写入，任一读回不符立即报错且不视为成功。宿主的会话查询派生索引文件由引擎在重启后的首次搜索时创建与增量维护，位于 power-dsh 自己的 profile 目录内，删除后自动重建；本功能不创建、不写入该文件。

关闭唯一开关立即关闭弹窗、撤销拦截并清空正文缓存，同时恢复引擎出厂默认（`openAt: 'never'` 与 `path: ':memory:'`），不记忆开启前的原值，与[停用官方搜索](../search-blocking/spec.md)的约定一致。引擎配置改动需**重启 DSH** 后生效（引擎在装配时挂载）；运行中索引禁用时的占位符说明重启要求。增强影响宿主全局会话搜索能力，原生侧栏也受同一引擎配置影响。与市场插件 `dsh-session-fulltext-search` 同时使用时两者写同一配置行，profile 配置优先于该插件的 bundle 层，不建议同时启用。

保留派生索引文件用于下次开启，不删除用户会话。关闭弹窗不会在后台主动建立索引；尚未重启时宿主原生侧栏的全文能力仍以已挂载的引擎配置为准。无后台轮询不代表零开销：首次加载与持久索引占用磁盘，已用正文保留内存缓存，搜索和变更补读按需执行。

### 内容索引（Host）

原生 `session-query-sqlite` 的查询计划在本机 412MB 派生索引上实测约 940ms：它对全部 MATCH 行（`dsh` 命中 9.4 万条）执行 `highlight()` 并计算 span 数后才排序取 20 条，且 `unicode61` tokenizer 匹配 token 而非任意子串（同一范围内 `搜索` 召回 96 条，字面扫描 669 条；`全文搜索` 为 0 条对 2 条）。因此 Host 侧提供只读内存索引 [content-index.ts](content-index.ts)：

- 首次内容搜索时只读打开 `<profileContext.home>/power-dsh/session-query-index.sqlite3`，校验 `application_id` 与 `user_version`（8）后，只载入当次可见候选中 `type IN ('user/message','assistant/message') AND surface='current'` 的正文及 revision；不提前载入子代理、归档或其他工作区的正文。切换到未缓存会话时按需读取，再复用缓存。
- 命中判定为不区分大小写的字面正则子串扫描，支持中文 1–2 字；按 Client 传入的活动顺序扫描候选，会话命中足够一页即停止。会话内选命中次数最多的消息，次数相同时选较新消息，最终仅为这一页生成 240 码点片段。
- 同一请求携带 `previewIds`（Client 侧当前页的标题匹配会话），Host 顺带返回这些会话最新一条消息的预览摘要，实测 3 个会话 0.2ms；预览只在该页需要时生成，不额外读库。
- 已有可读 SQLite 索引时，首次加载后先用持久源 revision 校验，仅补读变更项，不为初始化强制执行全局 FTS 同步。文件缺失或不可读时才经公开 `sessionQuery.searchSessions` 同步并重试加载；引擎公开配置仍为 `openAt: never` 时保留待重启状态，不读旧文件。并发初始化和 revision 检查分别复用同一任务。重复搜索不重开 SQLite、不全局同步、不重新枚举目录。
- 活跃会话通过公开 `sessions.get`、`Session.seq`、`Session.surface.contentGeneration` 检查版本。首次使用或复杂变化时优先借用 `observeSession` 的不可变切片，沿宿主已经折叠好的 `surface.nodes` 提取正文，不重新回放、深复制整段对话。冷会话优先用同一观察接口和公开 `buildSessionEventSearchDocuments` 生成规范文档；缺少可选能力时回退 `readSurface`。所有观察租约在成功、失败时均释放。
- 已缓存会话的普通消息由 `session/event` 增量提取并追加；替换、压缩、事件缺口、消息投影变化或同 id 会话实例替换使该会话失效，下一次涉及它的搜索才重建。监听只维护已经使用的缓存，默认关闭或尚未搜索时不保留会话 id，不在后台主动读取正文。
- 释放会话时标记该 id 待校验；下一次涉及它的查询从公开读取补齐。持久会话使用 SQLite 中的 revision 起点，首次初始化后最多每 30 秒在实际搜索时调用一次 `sessionPersistence.list`，只重读 revision 变化或新出现的候选会话，清除删除项。没有搜索就没有轮询；外部进程修改已有冷会话最多在下一次到期搜索时发现。服务替换、关闭增强或卸载清空缓存并隔离迟到响应。
- Client 将当前可见且属于所选工作区的会话 id 按最近活动排序传给 Host；Host 先限制候选范围，再按此顺序取满结果页，不让子代理、归档或其他工作区的命中占用名额。标题匹配与最近会话同样先筛选再截断。
- 索引不可用（文件缺失、`application_id`/`user_version` 不符、读取失败、行数超过 40 万）时返回 `available: false`，Client 静默回退原生服务，不显示错误；插件卸载时释放内存数据。
- 本功能不直接写入派生索引，由宿主公开查询同步它。关闭弹窗后不再请求正文或返回旧缓存；Host 同样检查唯一开关并清除缓存，即使旧索引文件保留也不读取。关闭或卸载会释放缓存，卸载中止未完成的宿主同步，迟到读取不得重新发布缓存。
- 增强正文在输入停顿 100ms 后执行；索引不可用时原生回退保持总计至少 250ms 的输入等待，并取消被新输入取代的请求。输入变化、切换工作区、关闭面板或关闭增强均取消旧请求的结果。缺少所需公开方法时保留原生搜索回退，不能把旧快照视为已同步。

## 接入与例外

本机 DSH `0.2.2-rc.3` 安装包的 `dsh-client-ui-workspace/lib/client.js` 中，宽栏与窄栏两处搜索按钮以 `type="button"`、`aria-label=t('search.sessions.aria')` 渲染，点击调用内部 `requestSearch()` 展开内联搜索；`ui-workspace` 未提供可替换搜索行为的公开 service 或 slot，`session.search` 快捷键（`session.search`，桌面 primary+K、网页 primary+Alt+K）由宿主 shortcuts 服务在 window 冒泡阶段处理。原生内联展开无法经公开接口改为弹窗，且该官方会话搜索面板在当前安装包与官方仓库已发布标签中不存在（截图为更新版本构建），故面板由本插件自绘；`session-query-sqlite` 的默认条目（`path: ':memory:'`、`openAt: 'never'`）与部署级开启方式核对自 `dsh-base` bundle 层与官方仓库 `session-query-sqlite` 源码。

用户已明确允许本功能接管搜索入口，作为「不查询其他插件 DOM」与不拦截宿主输入的两处相关例外：

1. 点击拦截：Client 以 window 捕获阶段 `click` 监听只遍历当前事件的 `composedPath()`，以 `tagName=BUTTON`、`type="button"`、`aria-label` 等于运行时 `ctx.locale.bind('workspace')('search.sessions.aria')` 解析值识别原生搜索按钮，随后停止传播并打开面板。locale 解析失败时返回键名原文，与真实按钮不匹配，功能静默退回原生行为。不扫描文档、不读取 React fiber、不依赖生成类名、不修改宿主节点。
2. 快捷键拦截：window 捕获阶段 `keydown` 监听按上文修饰键组合匹配 `code=KeyK`，随后停止传播并 `preventDefault`，在 shortcuts 服务（window 冒泡阶段）处理前打开面板。平台识别只读 `document.documentElement` 的 `data-platform`（桌面版标记，网页端无此属性）；不读取 shortcuts 配置，用户改绑原生快捷键后面板仍按默认组合接管，原组合可能同时触发内联展开，属已知限制。

面板挂载在 `ui-layout` 自 `0.2.0-rc.1` 起声明的 `shell.overlay` frame 级 list slot（官方文档定位为「frame-wide surface of your own」的新增席位），随功能始终注册，组件内自带样式节点；面板为自绘 `role="dialog"` 浮层（半透明遮罩＋圆角凸出阴影面板），全部颜色与几何使用主题别名 token（`--dsw-alias-bg-layer-1`、`--dsw-alias-border-*`、`--dsw-radius-*`、`--dsw-elevation-prominent` 等），不运行时导入内部 UI 组件或 CSS，无确认、表单或全局样式写入。打开会话复用 `uiWorkspace.openSession`，搜索复用注入的 `sessions` face，工作区名复用注入的 `workspaces` face（`list` 快照 `items`），均按渲染读取、不保持常驻订阅。搜索增强使用原生 `configEditor` 与 `profileContext.home`，写入机制与[停用官方搜索](../search-blocking/spec.md)相同。将来宿主提供搜索行为的公开接口或内置同款面板时优先迁移。

## 数据与权限

搜索弹窗唯一开关改写宿主 profile 的引擎配置与本插件偏好。派生索引由宿主创建与维护，本功能只读载入其中的用户和助手消息正文，并经公开查询读取活跃会话当前消息；不读取推理正文、独立工具结果、凭据或任意配置，不将正文写入另一个缓存文件，不发网络请求。Client 只接收结果页摘要与所需标题预览，另读取会话及工作区列表元数据。结果点击仅携带会话 id，等价于在原生列表中打开会话。
