# 显示版本号

## 标识、入口与范围

功能 id 为 `version-display`。入口：**设置 → PowerDSH → 通用 → 显示版本号**，`showVersion` 默认 `false`，通过宿主 settings 独立持久化；设置工具 `power_dsh_settings` 可读写同一偏好。

开启后在展开的侧栏品牌附近显示当前 DSH 宿主版本。显示值来自 Host `clientModules.graph().release.version` 或 Client 的 boot release，不使用 PowerDSH 的包版本，不硬编码更新目标。侧栏收起、偏好未就绪、功能关闭或没有可靠版本值时隐藏。

## 行为与数据

具备协议兼容的桌面更新桥时，点击版本号打开原生更新流程，可能开始下载，实际安装仍由宿主确认。普通浏览器或缺少更新桥时只显示版本，不发起更新请求。打开流程期间阻止重复提交，失败在入口旁提供错误，完成后允许再次尝试。

开关保存只改变显隐，不立即更新、不下载文件。功能不管理 Mod 的版本与升级，也不替换宿主品牌、账号或设置入口。版本读取与界面展示不接触凭据或用户文件；打开原生更新流程所需的网络与安装权限由宿主管理。

## 接入、生命周期与兼容

当前实现在 [Client 的 VersionBadge](../src/client.js)中，复用 Mod 自有的侧栏追加容器，只测量自身元素，观察器、订阅与组件状态随隐藏或卸载释放。关闭功能不影响原生更新能力，也不清除已保存偏好。

侧栏布局接入、平台定位与接口依据见[架构规范](architecture.md#侧栏接入)。macOS、Windows 的当前偏移不构成所有窗口比例与未来宿主布局的对齐保证；缺少兼容的桌面更新桥时保持只读。

## 验收条件与验证

- 默认关闭；保存开关只改变可见性，收起侧栏后不留下可点击入口。
- 展示宿主版本，桌面点击仅触发一次原生更新操作；Web 环境不能点击触发更新。
- 更新操作失败时结束忙碌状态并显示错误；隐藏或卸载后释放尺寸观察器与订阅。
- 配置读写通过宿主入口完成，保留其他功能偏好。

现有 [Client 行为测试](../tests/client.test.mjs)覆盖版本显示、Web 只读与原生更新入口，[Host 装配测试](../tests/host-wiring.test.mjs)覆盖实际管理命名空间上的偏好读写。实际桌面更新、下载、跨平台标题栏及窗口缩放尚未完整验收；不为验证显示功能而触发下载。
