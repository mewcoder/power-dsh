# 壁纸

## 标识、入口与范围

功能 id 为 `wallpaper`，主开关为 **设置 → PowerDSH → 界面**第一行的「开启自定义壁纸」（英文 `Enable custom wallpaper`），开关说明为「更换界面背景」／`Change the interface background`，配置键 `wallpaperEnabled` 默认关闭、独立持久化。此设置行分类为 `interface`、排序为 -1，位于快捷推理等级切换之前；「通用」不重复开关。PowerDSH 内部仅保留「通用、界面、管理、精简、其他」五个 Tab，id 为 `general`、`interface`、`enhancements`、`simplify`、`other`，默认选择通用，没有内部壁纸 Tab。

开启主开关后，在原生设置左侧栏注册独立「壁纸」／`Wallpaper` 入口及图标。其排序为 50.5，位于 PowerDSH（50）之后、全局指令（51）之前。入口为 **设置 → 壁纸**；主开关仅存在于 PowerDSH 界面首行，壁纸专页不重复主开关。关闭主开关移除该原生入口、图标和媒体效果，撤销未提交预览，保留当前选择、图片及调节值。没有官网流动背景独立开关、主页调节面板或背景侧栏底部快捷按钮。

壁纸专页拥有自己的「壁纸」／`Wallpaper` Title 与「选择壁纸并调整显示效果」／`Choose a wallpaper and adjust its appearance` 描述，遵循原生设置页标题基线。标题与描述下方直接展示四项缩略图 radio 选择，再依次显示「壁纸可见度」「壁纸模糊」两个滑块，不添加重复的「壁纸」字段标题。主开关、原生导航入口与专页 Title 各有明确职责，壁纸专页不重复主开关。控件、主题和错误反馈沿用宿主基线。

选择项固定为：

| 值 | 中文 | 英文 | 媒体 |
| --- | --- | --- | --- |
| `none` | 无壁纸 | None | 不挂载媒体，保留壁纸专页 |
| `flow` | 官网流动 | Homepage flow | 本项目既有的独立 WebGL 流动图案 |
| `seaside` | 大肥鱼 | Big fat fish | 用户指定的现用海景与鲸鱼图片，本地内置 JPEG |
| `custom` | 自定义 | Custom | 用户导入的本地图片 |

「大肥鱼」预制由用户明确指定的现用壁纸制成，保留原始 JPEG 字节；图片在构建时内嵌到 Client，不请求远程图片、不依赖 profile 中的自定义图片，也不改写现有选择。预制不提供替换／移除按钮，更换自定义图片不影响此预制。资源为 [seaside.json](../../../assets/wallpapers/seaside.json)，只含原图 data URL，原图为 2715×1500、2,102,697 字节，SHA-256 `3ce7069042d4286a7130953b36f0c1ee76dfc804f6c7a38c97140043fd5db07f`。使用 JSON 静态资源供严格 TypeScript 与 Node 源码检查共同读取，构建内联后无需运行时读取个人文件或新增公开资源导出。参考 Cindy `makecindy/cindy` 提交 `a32a54c0` 的缩略图选择、两个调节项与预览／提交思路，控件与主题遵循 DSH 规范。无视频、桌面透视或原生模糊能力。

## 配置与兼容

`wallpaperEnabled` 为可选布尔字段，缺省表示尚未明确选择，新安装等效 false；缺省且旧 `flowingBackgroundEnabled=true` 时兼容为启用。用户第一次切换后保存明确 true/false，不再使用旧启用状态。关闭开关撤销未提交预览和媒体效果，移除原生壁纸入口与图标，保留当前选择、图片与调节值；不恢复另一个独立流动效果。

`wallpaperSelection` 为可选字符串，取值为上述四项，新用户默认语义为 `none`；未知值（包含已移除的预制值）回退 `none`，不自动写盘或改成其他背景。缺省时按旧配置兼容：上一阶段已明确 `wallpaperEnabled=true` 则选 `custom`，保留自定义图片；否则旧 `flowingBackgroundEnabled=true` 时，旧 kind 为 `wallpaper` 选 `custom`，其他旧 kind 选 `flow`。新用户首次启用时明确保存 `none`，避免其启用开关被误判为旧自定义图片配置。启动读取兼容不自动写盘；显式保存的选择优先于所有旧类型字段。

`wallpaperVisibility` 为可选数值，0–100%、步进 1；`wallpaperBlur` 为可选数值，0–20px、步进 1。缺省时沿用对应旧背景可见度／模糊（模糊限制到 20），无旧选择时分别为 100 与 0。所有预制及自定义共用这两个值，切换预制不重置外观；选 `none` 保留它们但不执行渲染。旧图片存储位置及 `readWallpaper`／`saveWallpaper`／`clearWallpaper` RPC 不变。

可见度使所选媒体与主题基础底色混合；静态图片以主题底色遮罩实现，遮罩不透明度为 `1 - visibility / 100`。模糊只作用自有媒体，0px 关闭；静态图片按三个模糊半径扩边后由自有容器裁切，允许 cover 构图轻微扩大裁切。可见度为 0 时暂停实际模糊、禁用模糊滑块但保留数值，恢复后沿用原值。不改文字、卡片、输入框或宿主主题 token。

旧 `flowing-background` 模块仅保留五个隐藏配置键，不提供 UI、注册或副作用；`showBackgroundShortcut` 的旧保存值被忽略。兼容键及公共结构挂载授权见[退役流动背景模块](../flowing-background/spec.md)。

## 选择、导入与调节交互

预制采用缩略图 radio 选择组，当前值通过 `aria-checked` 表达，并以整张卡片周围的 1.5px 中性轮廓与主要文字色区分；轮廓贴合卡片外缘，缩略图、名称及自定义图片的操作区均包入框内，选中及其悬停状态均不增加整卡底色或阴影，不使用勾选角标；卡片按钮显式移除原生外观与阴影。焦点环仅用于键盘聚焦，选中与未选中卡片的几何尺寸保持一致。「无壁纸」与尚无图片的「自定义」预览区使用 `--dsw-alias-bg-module-platform` 主题分层底色和 0.5px 内描边，浅深主题下均能与页面背景区分；已有图片和流动缩略图保持原样。选择已有媒体立即保存，保存失败回到最近确认值并提供共享错误反馈；选择与外观写入串行，旧回执不得覆盖新选择。

- 选择 `none` 保留专页，不挂载图片、Canvas、动画或背景结构覆盖。
- 选择无图片的 `custom` 打开系统文件选择器，取消不改变当前选择；有已保存图片时可直接选择 `custom`。
- 成功导入图片后自动选择 `custom`；导入或选择保存失败保留已确认选择和可恢复状态，不显示假成功。
- 移除当前所选的自定义图片时选择回到 `none`；在其他预制下移除已保存的自定义图片时保留当前预制。
- radio 组使用 roving focus，只保留一个 Tab 停靠点；方向键循环、Home/End 移到首尾并选择。空的 `custom` 通过这些导航只获得焦点，需 Enter／Space 或点击明确激活后才打开文件选择器，避免方向键浏览时弹出系统窗口。

自定义图片的替换与移除按钮放在卡片底部名称右侧，常显并预留独立宽度，不遮挡图片或挤压名称；与 radio 按钮互为同级元素，避免嵌套交互控件。更换图片使用双向切换箭头图标，移除保留宿主垃圾桶图标；图标为 14px，按钮自身显式使用主题三级文字色，hover 或键盘聚焦时升为次级文字色，保留 28px 命中区。Tooltip 与可访问名称将更换操作写为「更换图片」／`Change image`。点击操作不同时触发预制选择。文件名和「PNG / JPEG / WebP · 最大 25 MB」只通过 Tooltip 提示，缩略图下方不再重复文件行、格式说明或操作行。

两个原生 range 参照 Cindy 滑块形态，命中区高 36px、轨道高 6px、滑块默认 16px，hover 放大到 18px、按下呈 22×16px；颜色与焦点使用 DSH token，不引入新的滑块依赖。按下滑块时只捕获指针和显示按压反馈，设置保持可见；同一主指针按住至少 200ms 且横向移动至少 4px 后，才临时隐藏原生设置弹窗及遮罩。单击、短按、快速拖动及长按不移动均不触发隐藏，数值仍按正常规则预览和保存；无需延迟计时器，松手或取消后迟到的移动事件不会激活隐藏。进入隐藏预览后，保留当前滑块、名称和数值在原位可见，并提供紧凑主题底板；页面挂载、几何位置、焦点和指针捕获均不变，背景即时预览。松手立即恢复同一个完整壁纸页，再异步保存最终值，不等待写盘。仅从自有 range 向上寻找具有 `data-shortcut-modal="settings"`、`role="dialog"`、`aria-modal="true"` 的原生面板，并核对 body 直接子级的 presentation 容器及唯一遮罩兄弟，以及 range 直接父级的自有滑块标记后，对设置容器临时写入 `visibility:hidden !important`，对该自有滑块行写入 `visibility:visible !important`；不关闭设置、不切换页面，不修改 opacity、display、pointer-events、焦点或全局 CSS。恢复保存原内联值和优先级，只撤回仍属于本次手势的写入，保留第三方后写值。结构不匹配或无法捕获指针时保持设置可见并提供共享错误反馈，仍可调节和保存。取消、失焦、权限丢失、切换壁纸、离页或卸载同步恢复显示并丢弃未提交值；切换包含乐观选择与保存失败后的本地回滚，即使配置源没有再次通知，也须立即取消待触发或已进入预览的手势。选择保存成功且当前壁纸未变时保留手势。进入隐藏、更新草稿及松手提交前再次校验手势起始选择，取消后的迟到指针事件不提交。键盘方向键、Home/End、PageUp/PageDown 可调整并提交，始终保留设置可见。指针取消、丢失捕获、控件失焦、窗口失焦或离开设置丢弃未提交预览，采用最新已保存值；拖回起点不写入。保存串行，滑块在保存期间可继续调整，已提交新值不被旧回执覆盖；失败回到最近确认值并显示共享错误反馈。关闭开关、配置不可用、失去写权限或卸载立即撤销未提交预览和副作用。

本次手势预览直接依据已安装 DSH `0.2.2-rc.1` 的设置模块核对：安装包与本地只读发行快照的 `dsh-client-ui-settings-general/lib/client.js` 完全一致（SHA-256 `e7c2795e2af43ea45c98c1a894daeaa58d71f1ec6fe081e5999d44cf63ccc047`）。该版没有临时隐藏的公共接口；原生关闭会卸载页面并清空 activeId，因此仅采用本节限定的祖先与自有滑块行的可见性适配，不调用内部 store、关闭回调或重新打开入口。

## 数据、挂载与生命周期

自定义文件只接受 PNG/JPEG/WebP、最大 25 MiB。复用 Host owner-only 队列、MIME／大小／名称校验、0600 临时文件原子写入及失败清理；数据仍存于 profile 的 `power-dsh/wallpaper.bin` 与 `wallpaper.json`。Client 校验后经 FileReader 和 RPC 交给 Host；失败保留已有图片和确认状态，读取失败可重试。旧请求及卸载后的回执不得覆盖新状态。没有额外网络、进程、凭据或第三方依赖。

挂载只复用[公共结构挂载授权边界](../flowing-background/spec.md#全局底层挂载与授权边界)中已核对的 AppFrame 底层适配及样式所有权恢复，最多一个背景层。自定义图片不创建 WebGL 或动画帧链；只有 `flow` 启动既有流动渲染，保留减少动效、隐藏暂停、节流、像素预算、WebGL 降级和资源清理。`none`、关闭、框架替换或卸载释放媒体、观察器、动画与临时表面覆盖，按所有权恢复第三方后写值。

## 验收与证据

- PowerDSH 保留通用、界面、管理、精简、其他五个内部 Tab，默认通用；界面首行是「开启自定义壁纸」，位于快捷推理等级切换之前。「通用」与壁纸专页均不重复主开关。
- 开启后注册原生设置左侧「壁纸」入口及图标，顺序为 PowerDSH、壁纸、全局指令；关闭移除入口、图标及效果，保留配置和图片。专页具有自身 Title／描述，其下直接展示四项缩略图 radio 与两个滑块，不重复字段标题；`none` 保留专页但无媒体和挂载副作用。自定义图片操作位于卡片底部名称右侧，文件名／格式仅 Tooltip，无下方重复文件行。
- 旧流动与旧自定义图片分别恢复为 `flow`／`custom`，显式选择不被旧配置覆盖，新用户首次开启明确保存 `none`。
- 预制点击立即保存、失败回滚；空自定义的导航不弹文件窗口，明确激活才选图，取消保持选择；导入自动选自定义，移除遵循当前／非当前选择规则。
- 拖动不写盘、松手一次提交，取消／失焦／离开撤销预览；并发确认、失败恢复与外部更新不丢最新值。0% 暂停模糊并保留偏好。
- 既有 Host 校验、安全存储、错误重试与卸载清理继续覆盖；自定义图片不联网、不启动 GPU 帧链。
