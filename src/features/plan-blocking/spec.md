# 停用 Plan 模式

## 入口与范围

功能 id 为 `plan-blocking`，在 **设置 → PowerDSH → 精简** 的 Todo 下方提供独立「停用 Plan 模式」开关，说明「停用新对话的内置计划模式」。`blockPlan` 默认 `false`，由宿主持久保存；UI 与 `power_dsh_settings` 共用 owner-only `setPlanBlocked`，通过共享 Host 队列串行执行。

用户确认仅需对新对话生效。只匹配 `@deepseek-ai/dsh-plan-mode`：全局条目通过原生 Plugin Manager 启停，模式中的直接与嵌套 group 条目通过原生 ConfigEditor 修改 `disabled`，保留 section、隔离声明、其他插件与元数据。开启停用，关闭启用，包括原本已停用的匹配条目，不记忆原启用状态。Web 默认停用全局 Plan、在各模式隔离提供 Plan，模式声明仍须单独处理。

保留 `@deepseek-ai/dsh-client-ui-plan`，不隐藏或删除历史计划卡片，不修改任何会话的计划状态或历史正文。Todo、目标、审批和沙箱策略不在范围内。不为旧 Agent 添加工具限制、执行 guard、命令遮蔽、退出状态或 pre-step 监听。

## 生效与生命周期

新建顶层对话使用修改后的模式代际；旧 Agent 派生的子代理可按原生规则继承旧代际。停用 Plan 时不再提供原生 `/plan` 命令及 `exit_plan_mode` 工具；原生 Plan UI 根据能力缺席处理入口。已打开对话继续持有旧代际，不强制刷新、退出或阻止其计划操作。关闭开关后，新建对话恢复计划能力。会话重新打开、切换模式或宿主重启后使用哪个代际由宿主决定，不为历史会话保存额外的功能快照。

Host 仅在 `agentPresets` 可用时提供策略执行；缺席时报错，不影响其他功能。模块卸载释放绑定并关闭共享队列，保存回调在取得锁后重新核对生命周期；不自动启用原生持久停用的条目。需要撤销精简时先关闭开关。

## 保存与失败

操作先更新模式声明并读回 composition inventory，再启停并读回全局条目，最后保存所属偏好并核对。只保存 `blockPlan`，保留其他偏好。没有受支持目标、模式缺失或数量变化、条件状态无法确认、原生需重启/警告/失败及偏好保存失败均明确报错。部分已完成的原生变更可能保留，沿用现有精简功能的重新执行恢复语义，不建立恢复记录或自动回滚。

设置保存期间即时显示目标值并禁止重复提交，失败读回已保存值，在对应行复用共享错误反馈。配置事件与模块启动不主动重写原生配置。模式 ConfigEditor 保存完整配置为 profile 覆盖，沿用宿主对上游默认值更新的处理。
